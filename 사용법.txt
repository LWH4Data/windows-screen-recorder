화면 녹화 — Windows / macOS

Windows 실행
1. ZIP을 받은 경우 폴더 전체를 압축 해제합니다.
2. ScreenRecorder.exe를 더블클릭합니다. exe만 따로 옮기면 실행되지 않습니다.
3. Windows 10/11 64비트(x64)용입니다. 별도 Python/Node 설치는 필요 없습니다.

Mac 실행
1. Apple Silicon(M1/M2/M3/M4 등)은 arm64, Intel Mac은 x64 배포를 사용합니다.
2. Screen Recorder.app을 응용 프로그램 폴더에 복사하고 실행합니다.
   macOS 13 이상이 필요하며, 별도 Node.js 설치는 필요 없습니다.
3. 시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음
   (또는 화면 기록)에서 Screen Recorder를 허용합니다. 앱에서 설정을 열 수 있습니다.
   허용 후 시스템이 요청하면 앱을 종료하고 다시 실행합니다.
4. 마이크 옵션을 켜고 처음 녹화를 시작하면 마이크 권한을 요청합니다.
5. 컴퓨터 소리는 macOS 14.2 이상에서 지원합니다. 이전 버전에서는 화면과
   마이크만 녹화할 수 있습니다. 오디오 권한 요청도 허용해 주세요.
6. Mac은 로컬 ad hoc 서명이며 Apple Developer ID 서명·공증되지 않았습니다.
   다운로드 앱이 차단되면 출처를 확인한 뒤 시스템 설정의 해당 앱 열기 안내를 따르세요.

녹화
1. 전체 화면 또는 특정 창 탭에서 녹화 대상을 클릭합니다.
2. 영상 크기, 프레임, 화질, 저장 형식을 선택합니다.
   기본은 최대 1080p / 30fps / 표준 화질입니다.
   원본이 작으면 해상도를 억지로 키우지 않습니다. 화면 비율도 유지합니다.
3. 컴퓨터 소리와 마이크를 선택합니다. Windows 개인정보 설정 또는 Mac
   시스템 설정에서 앱의 마이크 접근을 허용해야 할 수 있습니다.
   특정 창을 선택해도 컴퓨터 전체의 소리가 녹음됩니다.
   시스템 소리와 마이크를 함께 쓰면 헤드폰 사용이 음성 울림을 줄이는 데 도움이 됩니다.
4. 녹화 시작을 누르고 저장할 파일 위치와 이름을 선택합니다.
   이미 존재하는 파일은 덮어쓰지 않습니다. 다른 파일 이름을 선택하세요.
5. 창을 최소화해 작업합니다. 기본 설정으로 자동 최소화합니다.
6. Ctrl + Shift + F9: 일시정지 / 재개
   Ctrl + Shift + F10: 녹화 중지
   Mac: Cmd + Shift + F9(일시정지/재개), Cmd + Shift + F10(중지)
   기능 키가 음량 등을 조절하면 Fn 키도 함께 누릅니다.
   Windows 알림 영역 / Mac 메뉴 막대에서도 창 열기 / 녹화 중지가 가능합니다.
7. 저장 완료 안내가 나타나면 저장 위치 열기로 파일을 확인합니다.

YouTube용
- MP4가 지원되는 PC에서는 MP4를 기본으로 선택합니다.
- MP4를 지원하지 않는 경우 WebM이 표시됩니다. MP4가 필요하면 영상 편집기에서 변환합니다.
- 표준 1080p/30fps는 약 8Mbps를 요청합니다. 실제 인코딩 비트레이트와 프레임은 PC에 따라 달라집니다.
- 30fps는 화면 설명과 강의 영상에 적합합니다. 빠른 움직임은 60fps를 선택할 수 있습니다.
- 업로드나 편집 전에 짧은 시험 녹화로 영상과 소리가 정상인지 확인하세요.

알아둘 점
- 화면의 현재 내용과 선택한 소리가 녹화됩니다. 저장 대화상자에서 취소하면 녹화하지 않습니다.
- 프로그램을 정상적으로 닫으면 녹화 중인 영상을 저장하고 종료합니다.
- 기록 중에는 <파일명>.recording 임시 파일을 사용합니다. 강제 종료나 저장 오류가 있으면
  이 파일이 남을 수 있습니다. 영상 편집기 등에서 복구를 시도할 수 있으나 복구를 보장하지 않습니다.
- 긴 녹화는 충분한 디스크 공간이 필요합니다. 표준 8Mbps 요청 기준 1시간 영상은 약 3.7GB입니다.
- 이 앱 창은 선택 목록에서 제외되지만 전체 화면 녹화에는 앱 창, 알림, 저장 대화상자가 보일 수 있습니다.
- 전체 화면 대신 특정 창을 녹화하면 다른 창이나 바탕화면이 영상에 들어갈 가능성을 줄일 수 있습니다.
- 복사 방지 영상, 관리자 권한 창, 잠긴 화면 등은 검은 화면으로 보이거나 녹화가 중단될 수 있습니다.
- 자유 영역 선택, 웹캠, 영상 편집, 자동 YouTube 업로드는 이 버전에 포함되지 않습니다.
- 전자 서명되지 않은 로컬 제작 앱입니다. 배포 환경에 따라 Windows 실행 확인이 나타날 수 있습니다.

소스 실행
소스 ZIP을 풀거나 GitHub 저장소를 내려받고 해당 폴더에서 Node.js/npm으로 다음을 실행합니다.
  npm ci
  npm start
Mac의 시스템 오디오 녹화는 배포 .app을 직접 실행해 확인하세요. 소스 실행은
Electron/터미널의 권한과 오디오 사용 선언에 따라 무음일 수 있습니다.
npm 환경이 설치 스크립트를 차단한 경우:
  node node_modules/electron/install.js

소스 테스트
  npm test
녹화 파일 저장 로직을 검사합니다. 실제 화면과 오디오 장치의 동작은 짧은 시험 녹화로 확인하세요.

Windows / Mac 배포 폴더 생성
배포 대상 운영체제에서 같은 아키텍처의 Node.js/Electron을 설치한 뒤:
  npm run package
Windows: dist/ScreenRecorder-Windows
Mac: dist/ScreenRecorder-macOS-arm64 또는 dist/ScreenRecorder-macOS-x64
위 폴더가 생성됩니다. 이 폴더 전체를 ZIP으로 묶어서 배포하세요.
Electron 런타임과 그 라이선스 안내가 포함되므로 exe만 따로 전달하지 마세요.
이미 같은 폴더가 있으면 덮어쓰지 않습니다. 기존 배포를 따로 보관하거나
SCREEN_RECORDER_OUTPUT_DIR 환경 변수로 다른 출력 폴더를 지정할 수 있습니다.

프로그램은 서버로 영상을 전송하지 않습니다. 영상은 사용자가 선택한 로컬 경로에 저장합니다.
